# Ngenzeni Enterprise (PTY) LTD

Construction company website built with Next.js, React and Lenis. Includes responsive layouts, smooth scrolling, animated headings, service guides, FAQs and a WhatsApp enquiry form.

The application is in [`ngenzeni-enterprise/`](./ngenzeni-enterprise).

## Run locally

```sh
cd ngenzeni-enterprise
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Production build

```sh
cd ngenzeni-enterprise
npm run build
npm start
```

For hosting services that ask for a project root, select `ngenzeni-enterprise`.

See the [application README](./ngenzeni-enterprise/README.md) for features and editing instructions, and [asset sources](./ngenzeni-enterprise/ASSETS.md) for image credits.
